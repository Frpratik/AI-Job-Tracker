# JobTracker

JobTracker is a mobile-first job-search management platform. The repository is
organized as a monorepo so the mobile client, API, infrastructure, and product
documentation evolve together without coupling their release cycles.

## Repository layout

- `backend/` — Django REST Framework API
- `mobile/` — Flutter Android/iOS client
- `infra/` — local and deployment infrastructure
- `docs/` — architecture and operating documentation

See [docs/development.md](docs/development.md) for local setup.
