# Phase 1 — Foundation

## Delivered

- Flutter Android/iOS project with Riverpod, guarded routing, secure JWT storage,
  token refresh, responsive authentication screens, design tokens, light/dark/
  system themes, and the primary five-destination shell.
- Django REST Framework API with custom email-based users, onboarding profile,
  JWT rotation/blacklisting, registration, login, logout, current-user profile,
  email verification, password reset, throttling, structured errors, and OpenAPI.
- PostgreSQL Docker development service, environment template, backend container,
  and CI checks for both applications.

## Deferred by phase boundary

- Application models and CRUD, dashboard data, search, and filters: Phase 2.
- Interviews, reminders, calendar, and notifications: Phase 3.
- Documents and private object storage: Phase 4.
- Production email provider, hosting, monitoring, and backups: Phase 9.
